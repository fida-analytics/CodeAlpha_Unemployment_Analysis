
# Unemployment Analysis with Python

## CodeAlpha Data Science Internship - Task 2

### Project Overview
This project focuses on analyzing unemployment trends in India using Python.

The main objective is to explore unemployment patterns, understand regional differences, and study the impact of COVID-19 on unemployment rates.

### Dataset
Dataset: Unemployment in India.csv

The dataset contains information about:
- Region
- Date
- Frequency
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Longitude
- Latitude

### Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

### Project Tasks
- Data loading and cleaning
- Exploratory Data Analysis (EDA)
- Missing value analysis
- Statistical analysis
- Monthly unemployment trend visualization
- Region-wise unemployment comparison
- COVID-19 impact analysis
- Correlation heatmap

### Visualizations
The project includes:
- Monthly unemployment rate graph
- Region-wise unemployment rate graph
- COVID-19 impact comparison
- Correlation heatmap

### Key Learning Outcomes
- Data cleaning using Pandas
- Data analysis and exploration
- Data visualization
- Understanding unemployment trends
- Analyzing the impact of COVID-19

### How to Run the Project

Install required libraries:

pip install pandas matplotlib seaborn

Run the Python file:

python unemployment_analysis.py

- unemployment_analysis.py: Python source code
